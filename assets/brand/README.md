# DreamScaler logo

Original PNG artwork supplied for DreamScaler. Keep colours, proportions and transparency intact.

- `DreamScaler128x128-trans-back.png`: compact transparent logo for headers and browser icons.
- `DreamScaler1024x1024.png`: large transparent logo for the startup screen and larger placements.
- `DreamScaler128x128-white-back.png`: compact logo with a white background.
- `DreamScaler1024x1024-white-back.png`: large logo with a white background.

The same originals are stored in the standalone app (`ui/assets/brand`) and website (`assets/brand`) so both projects work independently.
